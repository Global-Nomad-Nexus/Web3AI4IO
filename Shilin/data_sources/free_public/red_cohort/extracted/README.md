# RED-COHORT-2026-v1

A public, reproducibility-grade dataset of 1,012 persistent sniper-cohort detections on the Solana pump.fun bonding-curve marketplace, derived from 1,578,333 buyer events across 166,098 token launches observed between 2026-06-12 and 2026-06-26 (15 days continuous).

This dataset accompanies the working paper:

> Kamat, A. U. (2026). *Coordinated Sniper Cohorts on Pump.fun: Detection of 1,012 Persistent Wallet Rings and the Limits of Naive Causal Inference for First-Hour Buyer Flow.* Working paper, arXiv + SSRN (in submission).

## Catalogue schema (`sniper_cohorts.jsonl`)

Each line is a JSON object with the following fields:

| Field | Type | Description |
|---|---|---|
| `wallets` | array of strings | Solana base-58 wallet addresses comprising the cohort. |
| `cohort_size` | int | Number of wallets (length of `wallets`). |
| `n_launches` | int | Number of distinct mints where ≥2 cohort wallets appeared among the first 10 buyers. |
| `first_seen` | int | Unix timestamp (seconds) of the first observation of this cohort co-firing. |
| `last_seen` | int | Unix timestamp (seconds) of the most recent observation. |
| `first_seen_iso` | string | ISO-8601 representation of `first_seen`. |
| `last_seen_iso` | string | ISO-8601 representation of `last_seen`. |
| `avg_first_rank` | float | Mean first-buyer rank of the cohort across all touched launches. |
| `sol_total` | float | Sum of `sol_in` across all cohort buyer events. |
| `score` | float | Detection score: `(n_launches × 10) + (5 / max(avg_first_rank, 1)) + sqrt(sol_total)`. Higher = more launches hit, earlier average first-buyer rank, more SOL deployed. |
| `mints_hit` | array of objects | Per-mint detail: `{mint, n_wallets, first_rank, min_time, max_time, sum_sol}`. |

The catalogue is sorted in descending order of `score`.

## Reproducing the detection from raw on-chain data

1. Collect pump.fun buyer events as JSONL with the schema: `{mint, wallet, slot, blockTime, sol_in, tx_sig, buyer_rank}`. The author's collection infrastructure is a read-only RPC listener; any equivalent data source with the same schema will work.
2. Save the buyer events as `pumpfun_buyers.jsonl`.
3. Run `python3 analyze_sniper_cohorts.py`. The script reads `pumpfun_buyers.jsonl` (path is hard-coded; edit the constants at the top of the script if needed), and emits `sniper_cohorts.jsonl` and `sniper_cohorts_report.md`.
4. Verify the catalogue size matches expectations for your observation window. The 15-day window in this release yielded 1,012 cohorts; observation windows of substantially different length will yield different counts.

## Ethics

All data are public Solana base-58 addresses. No personally identifying information is included. One wallet address in the source corpus included an ethnically offensive vanity prefix; in this public release that prefix has been redacted to `[REDACTED]` while the remainder of the address is preserved so the redaction does not impair reproducibility against the underlying on-chain data. The redaction applies to:

- `sniper_cohorts.jsonl` (one cohort entry)
- `sniper_cohorts_intra.jsonl.gz` (three buyer-event entries)
- `sniper_cohorts_report.md` (one wallet rendering)

Researchers who require the un-redacted address for verification against on-chain block explorers can recover it independently from any public Solana RPC by querying the cohort's other wallets' transactions; we choose not to publish the offensive string ourselves.
